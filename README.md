# Mitsuki Extension

Browser extension for [Mitsuki](https://github.com/baoueb/Mitsuki), a Japanese flashcard and dictionary app for Mac and iPhone. It lets you learn Japanese from subtitles while you watch.

Learn more at [mitsukiapp.me](https://mitsukiapp.me).

## Install (manual)

Builds are published as [releases](https://github.com/baoueb/mitsuki-extension/releases).

1. Download the latest `mitsuki-extension-*.zip` from the releases page and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the unzipped folder.
